# Ръчно проверени заглавия и легенди

Един файл за том (`vol1-3.jsonl`, `vol4.jsonl`), по един JSON ред за карта:

```json
{"id": "Ф 36",
 "title": "Застъпници на стб. ѣ под ударение пред шушкави съгласни …",
 "items": [
   {"i": 1, "group": "1. Широки застъпници", "text": "ê ('ê, 'ä) – грêшна, гр'äшна и др.", "norm": false},
   {"i": 3, "group": "2. Тесни застъпници", "text": "е ('е, ѐ) – грèшна, грѐшна и др.", "norm": true}],
 "extra": ["друга лексема (Н)"],
 "note": ""}
```

- `i` е номерът на цветното квадратче, както е открито автоматично (колона `item` в слоя
  `legend` на GeoPackage-а); така текстът се свързва с извлечения ареал.
- `text` е преписан от сканираната легенда. Ударенията и диакритиките са запазени доколкото
  се четат при 150 dpi. Старобългарските думи са предадени с кирилица (ѣ, ѫ, ѧ, ъ, ь).
- `norm`: `true`, ако формата съвпада с книжовната норма (за акцентните карти: книжовното
  ударение; за лексикалните: книжовната дума); `false`, ако не; `null`, ако няма смисъл
  (напр. „друга лексема“).
- `extra`: елементи от легендата без квадратче (щриховки, знаци, изоглоси).
- `note`: бележка при несъответствие (напр. цвят на картата, който липсва в легендата).
